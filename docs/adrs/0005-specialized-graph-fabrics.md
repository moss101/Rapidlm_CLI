# ADR 0005 — Specialized graph fabrics

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Keep Runtime/Knowledge/Workspace/Evidence projections specialized but typed-linked.

## Rationale

One giant graph store would couple unrelated access patterns and operational truth.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
