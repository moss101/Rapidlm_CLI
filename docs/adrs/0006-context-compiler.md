# ADR 0006 — Context compiler

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Compile bounded provenance/freshness-bearing ContextPackets using hybrid retrieval/MMR.

## Rationale

Token budget and staleness require explicit context engineering.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
