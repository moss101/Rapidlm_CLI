# ADR 0007 — Read-only Context Scouts

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Use narrow scouts for non-trivial discovery and exhaustive negative findings.

## Rationale

Reduces expensive orchestrator search and improves coverage evidence.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
