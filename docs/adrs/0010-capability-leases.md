# ADR 0010 — Executor-validated capability leases

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Policy broker issues scoped signed leases rechecked by executors.

## Rationale

Tool visibility/approval alone is not a security boundary.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
