# ADR 0012 — Evidence-backed host completion

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Model proposes completion; host evaluates criteria/current evidence/verifier.

## Rationale

Prevents confident narrative from becoming terminal state.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
