# ADR 0013 — Independent verifier

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Proof-required goals use a separate verifier/oracle context.

## Rationale

Self-verification is correlated and may repeat implementation assumptions.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
