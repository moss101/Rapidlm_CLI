# ADR 0014 — Warm resource pool

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Lease sanitized warm containers/browser/mobile/remote resources.

## Rationale

Reduces startup latency while preserving isolation through generations/sanitation.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
