# ADR 0017 — WASM plugin default

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Use capability-declared WASM components for in-process extensibility.

## Rationale

Powerful extension surface needs strong ambient-authority limits.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
