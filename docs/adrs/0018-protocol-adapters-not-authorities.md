# ADR 0018 — ACP/MCP/external agents as adapters

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

External protocols/executors remain under kernel/graph/policy authority.

## Rationale

Avoid parallel session/policy/workflow systems.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
