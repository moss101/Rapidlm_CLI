# ADR 0019 — Preference is soft evidence

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

Learn scoped/decaying preferences from feedback; never override explicit authority.

## Rationale

Personalization should improve decisions without becoming hidden policy.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
