# ADR 0020 — Migration over rewrite

**Status:** Accepted for V3 baseline  
**Date:** 2026-08-24

## Decision

V3 adapts working V2 primitives after audit rather than wholesale replacement.

## Rationale

Preserves maturity and lowers regression risk.

## Consequences

Implementation tasks must preserve this decision unless a superseding ADR records new evidence, migration and compatibility/security impact.
