# Preference / Trajectory / Session Insights Evals

Synthetic accept/reject/edit histories test scope, confidence, support/contradiction and decay. Preferences never override explicit instruction/rule/policy. Trajectory export excludes hidden reasoning/secret content. Candidate prompt/router/context/preference experiments require held-out improvement without security/correctness regression. Insights must cite observable evidence.
## Common gate
Run against production contracts. Prefer deterministic assertions before model judges. Record exact fixture/version/model/prompt/context/tool schemas. A security/data-loss/duplicate-effect/false-completion regression is a hard failure regardless of aggregate score.
