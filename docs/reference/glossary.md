# Glossary

- **Runtime Graph:** host-owned execution IR.
- **Graph revision:** immutable snapshot/delta generation of Runtime Graph.
- **Node attempt:** one execution attempt of a logical node.
- **ContextPacket:** bounded provenance/freshness-bearing prompt context selected for a node.
- **Context Scout:** read-only investigation agent producing structured coverage evidence.
- **WorkspaceView:** isolated logical filesystem state.
- **WorkspaceTransaction:** preimage-aware proposed/applied code change.
- **CapabilityLease:** scoped short-lived executor authorization.
- **Operation Journal:** external-effect prepare/execute/commit/uncertain/reconcile ledger.
- **Evidence:** observation/source/artifact supporting or contradicting a claim.
- **Verification:** independent oracle verdict over claim/criterion evidence.
- **Observation generation:** version of a computer surface; input cannot use stale generation.
- **ControlLease:** mutable terminal/desktop/mobile/workspace input ownership.
- **Playbook:** parameterized template that compiles to an initial Runtime Graph.
- **Preference:** soft learned tendency with provenance/scope/confidence/decay.
