# Competitive Adoption and Licensing Policy

1. Prefer reimplementation of architectural patterns over copying code.
2. Never copy proprietary system-prompt wording; write RapidLM prompts from principles/requirements.
3. Before open-source code reuse record repository, exact revision, license, NOTICE obligations and modification boundaries.
4. Keep third-party adapters isolated behind RapidLM contracts so upstream architecture does not become the kernel.
5. Reverse-engineered/captured behavior may guide interoperability/architecture tests but must be described narrowly as observed in the captured version, not universal current behavior.
6. Competitive benchmark claims are source-reported until independently reproduced in RapidLM Eval Harness.
