# Conversation Compaction Prompt

```text
Produce a durable continuation summary, not a prose recap. Preserve: user goal and explicit constraints; unresolved questions; decisions and their reasons; exact files/symbols changed; tests/errors/evidence; active goal/budget state; agent/job handles; approvals/policy constraints; relevant read-set content hashes; next actionable step. Omit conversational filler, repeated source text and hidden reasoning. Never invent completion. Mark uncertain/stale information explicitly.
```
