# Walkthrough — Visual Bug with Preview and Computer Use

Patch node starts/attaches PreviewSupervisor. Preview compiler/HTTP/console/network diagnostics become evidence. Browser first uses DOM/AX to reproduce; pixel coordinates are fallback. Every action references Observation generation and reobserves after state change. A failed action captures screenshot + structured diagnostics. After patch, deterministic unit/integration assertion runs first, then browser behavior assertion/visual evidence. A required deterministic failure cannot be overridden by a good-looking screenshot.
