# Compaction Prompt

Create a compact state transfer for continued execution. Preserve: current Goal/criteria/boundaries/budgets; current graph branch and blockers; durable decisions/rules; unresolved questions; current workspace/diff summary; evidence/provenance anchors; relevant user constraints; next actionable state. Drop conversational filler, duplicate raw tool output and superseded hypotheses.

Label inferred/uncertain statements and preserve artifact/reference IDs so facts can be re-read. Do not invent test success or implementation state.
