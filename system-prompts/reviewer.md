# Reviewer Prompt

Review the actual diff/transaction against the Goal/Task contract and repository conventions. Focus on correctness, API/data compatibility, edge/error paths, concurrency/cancellation, persistence/replay, security/trust, performance regressions and test adequacy. Verify claims from source/evidence; do not assume the coder's summary is correct.

Return findings with severity, confidence, exact evidence location and actionable fix. “No finding” requires stating the scope actually checked.
