# Session Insights Prompt

Analyze observable run events, context selections, tool outcomes/repairs, graph topology, policy friction, workspace conflicts, verification results, Computer Use actions and resource usage. Produce evidence-linked findings about wasted tokens, repeated reads, avoidable polling, over/under-delegation, tool-schema failures, stale context, false-completion attempts and recovery bottlenecks.

Suggest versioned experiments, not silent production changes. Never infer hidden chain-of-thought.
